Значение вне отображаемого диапазона RGB — цвет обрезан до ближайшего допустимого.

XYZ

Координаты цвета CIE XYZ для источника D65.

Lab

CIE L*a*b*, белая точка D65 (95.047, 100, 108.883).

HLS

Оттенок / яркость / насыщенность (алгоритм Фоли — ван Дама).

H не определён при S = 0 — сохранено последнее значение
RGB↔XYZ — по матрицам D65; XYZ↔Lab — стандартные формулы CIE (f(t)=t^(1/3) при t>0.008856); HLS↔RGB — алгоритм Фоли — ван Дама. Значения, не попадающие в диапазон отображаемых sRGB-цветов, обрезаются до ближайшего допустимого с предупреждением.
